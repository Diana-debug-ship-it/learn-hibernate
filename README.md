# Java Hibernate Integration (Spring Java-Based Configuration)

Проект посвящен глубокому изучению ORM-фреймворка Hibernate, проектированию сложных реляционных моделей данных и ручной настройке интеграции Hibernate со Spring через Java-конфигурацию (без использования Spring Boot Auto-Configuration).

## 🛠️ Технологический стек и инструменты
* **Язык разработки:** Java
* **ORM Фреймворк:** Hibernate ORM
* **Конфигурация:** Продвинутый Java-Based подход (`@Configuration`, `@Bean`) вместо XML.
* **База данных:** PostgreSQL
* **Фреймворк:** Spring Framework Core (управление компонентами через IoC-контейнер).

## 🏗️ Проектирование доменной модели (Сущности)
На примере сущностей (`Course`, `Student`, `User`, `Group`, `Post` и др.) реализованы и закреплены ключевые концепции ORM:
1. **Маппинг ассоциаций (Entity Relationships):**
   * `@OneToOne` (Один-к-одному) — Связь пользователя и его расширенной анкеты (`Student` <-> `Profile`).
   * `@OneToMany` / `@ManyToOne` (Один-ко-многим / Многие-к-одному) — Связь пользователя и его публикаций (`User` <-> `Post`), а также распределение по группам (`Group` <-> `Student`).
   * `@ManyToMany` (Многие-ко-многим) — Организация записи студентов на учебные курсы (`Student` <-> `Course`).
2. **Управление схемой данных:** Использование стратегии `hibernate.hbm2ddl.auto = update` для автоматической генерации и обновления таблиц в PostgreSQL на основе аннотированных Java-классов.
3. **Логирование запросов:** Включение `hibernate.show_sql = true` для детального анализа и оптимизации генерируемого SQL-кода в консоли.
